# CLAUDE.md

Guidance for working in this repository.

## What this is

A single-page personal portfolio (`yoisha`) — hero, projects, and hackathons
sections on one scrolling page. It is **content-driven**: the visible content
lives in plain TypeScript config files, not in the components.

## Stack

- **Next.js 15** (App Router) + **React 19**
- **TypeScript 5** (strict, `target: ES2022`)
- **Tailwind CSS v4** (CSS-first config in `src/styles/globals.css`, no
  `tailwind.config.js`)
- **shadcn/ui** primitives (`src/components/ui`) + a few **magicui** buttons
- **motion** (Framer Motion) for the scroll parallax, **lenis** for smooth scroll
- **next-themes** locked to dark (`forcedTheme="dark"`)
- **@t3-oss/env-nextjs** + **zod** for validated env vars
- **pnpm** package manager, **ESLint 9 flat config**, **Prettier**

## Commands

```bash
pnpm dev          # dev server (Turbopack off by default)
pnpm build        # production build (also type-checks and lints)
pnpm start        # serve the production build
pnpm lint         # eslint . (flat config, next/core-web-vitals)
pnpm lint:fix     # eslint . --fix
pnpm format       # prettier --write ./src
pnpm format:check # prettier --check ./src
```

`pnpm build` requires `NEXT_PUBLIC_APP_URL` to be set (env is validated at
build time), e.g. `NEXT_PUBLIC_APP_URL=http://localhost:3000 pnpm build`.

## Environment variables

Defined and validated in `src/env.mjs`. Copy `.env.example` to `.env.local`.

| Variable               | Required | Purpose                          |
| ---------------------- | -------- | -------------------------------- |
| `NEXT_PUBLIC_APP_URL`  | yes      | Canonical/OG/sitemap base URL    |
| `NEXT_PUBLIC_GA_ID`    | no       | Google Analytics (loaded if set) |

Access env via `import { env } from "@/env.mjs"` — never read `process.env`
directly in app code.

## Architecture

```
src/
  app/
    layout.tsx           # metadata, fonts, providers (theme, lenis, toaster, analytics)
    page.tsx             # composes the three sections + parallax background ("use client")
    opengraph-image.tsx  # dynamic 1200x630 OG card via next/og ImageResponse
    twitter-image.tsx    # re-exports opengraph-image
    robots.ts            # robots.txt route
    sitemap.ts           # sitemap.xml route
    Air.woff2 / AirMono.woff2  # local serif + mono fonts
  components/
    hero-section.tsx, project-section.tsx, hackathon-section.tsx
    lenis-provider.tsx, theme-provider.tsx, mode-toggle.tsx
    ui/                  # shadcn/ui primitives (vendored — regenerated by `shadcn add`)
    magicui/             # animated button variants (vendored)
  config/
    site.ts              # identity, social links, keywords
    works.ts             # PROJECTS + HACKATHONS data (the main content)
    registry.ts          # chain + organization metadata referenced by works.ts
  lib/utils.ts           # cn() = clsx + tailwind-merge
  styles/globals.css     # Tailwind v4 @theme tokens, CSS variables, keyframes
  types/index.d.ts
```

## Editing content (the common task)

- **Add/edit a project or hackathon** → `src/config/works.ts`. `PROJECTS` is
  `Project[]` and `HACKATHONS` is `Hackathon[]` (types declared at the top of
  the file). A project's `w` (organization) and `chain` must be **keys that
  exist in `src/config/registry.ts`** — using an unknown name is a compile
  error, by design. Add the org/chain to `registry.ts` first.
- **Add a chain or organization** → `src/config/registry.ts` (`REGISTRY`,
  written with `satisfies` so the keys stay literal and type-checked).
- **Change name / social links / SEO keywords** → `src/config/site.ts`.

## Conventions & gotchas

- **Theme is forced dark** (`forcedTheme="dark"` in `layout.tsx`). The
  `mode-toggle` component exists but is not rendered.
- **The hero background is a remote giphy GIF** in `page.tsx` — this is
  intentional. `public/gradient.webp` is an unused alternate asset.
- **Remote logos use raw `<img>`** (with `alt` + dimensions), not `next/image`,
  because they come from many third-party hosts; `no-img-element` is disabled
  per-line where this is deliberate. App images you control should use
  `next/image`.
- `src/components/ui/**` and `src/components/magicui/**` are **vendored** — they
  can be overwritten by `npx shadcn add`, so avoid hand-editing them.
- Imports are auto-sorted by `@ianvs/prettier-plugin-sort-imports` (see
  `prettier.config.js`); run `pnpm format` rather than hand-ordering imports.
- After changes, run `pnpm lint` and a `pnpm build` — the build both
  type-checks and lints.

## Deployment

Deployed on **Vercel**. Set `NEXT_PUBLIC_APP_URL` (and optionally
`NEXT_PUBLIC_GA_ID`) in the project's environment variables.
